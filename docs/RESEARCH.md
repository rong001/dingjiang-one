## 从 JD 到系统能力

| JD 诉求 | 设计判断 | 前端表达 |
| --- | --- | --- |
| 已有 TOC 中台，打通 TOB | 用统一客户、产品和订单口径贯通两类渠道 | 渠道 / 业务类型筛选、客户档案、订单追溯 |
| 财务中台、成本归集 | 财务结果应可回到来源订单与费用事实 | 结算差异、贡献利润、平衡凭证、关账检查 |
| 采购、WMS、生产协同 | 需求、在途、可用库存和交付状态应共享 | 订单关联采购、审批收货、库存与工单 |
| ERP / MES / PLM 集成 | 保留底层职责，在经营层串联对象与版本 | BOM、工单、集成工作台、主数据质量 |
| IPO 合规与数据治理 | 优先统一口径、角色职责与证据可追溯性 | 控制复核、审计日志、权限交互、数据问题闭环 |
| 跨境网络、隐私与广告归因 | 区域责任、业务连续性与测量同意需共同管理 | 区域设施、恢复流程、营销同意与归因视图 |
| IT 预算、资产与供应商管理 | 项目投入应与预算承诺和责任人关联 | 项目预算、资产视图、供应商档案 |

以上系统能力是根据 JD 与公开业务作出的设计推断，不是公司内部系统现状调查结论。

## 五项视觉表面

- 字体：实际使用 Segoe UI / Microsoft YaHei 系统回退，标题 27px、侧栏 14px、表格 12px、辅助文本 10–12px。层级明确，数字列采用 tabular-nums。源图字体不可作为真实字体文件读取，采用可稳定显示中文的系统字体；已检查标题、客户名、金额和导航没有不可接受的裁切。
- 间距与布局：238px 侧栏、64px 顶栏、四列指标、主图表与两张右侧卡片、六段链路、订单表。石墨采用表格与订单详情双栏。窄屏顺序堆叠，表格在自身区域横向滚动。
- 色彩：靛蓝浅画布配海军蓝侧栏；石墨白色侧栏配深石墨选中态与蓝色操作；深海使用深蓝画布与浅蓝强调。状态色与焦点轮廓贯穿所有页面，修复了石墨 hover 对比问题。

- 内容：界面已移除演示环境、mock、面试版等标记。金额和计数来自当前业务方案。关于页和 README 明确合成样本、浏览器本地保存及非官方系统边界。
